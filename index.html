    About EngineerTools

    EngineerTools is a free, browser-based collection of engineering calculators designed for students, technicians, researchers, and engineers.

    All calculations run locally in your browser. No data is sent to any server. No account is required.

    Features

    • Electrical & electronics calculators (Ohm's Law, Power, Voltage Divider, Three-Phase, Resistor Color Code, Capacitor, Inductor, Transformer, LED Resistor)
    • Mechanical & fluid calculators (Beam Deflection, Torque, Shaft Power, Gear Design, Hydraulic Jack, Pump Head, Fluid Pressure)
    • Energy, mechanical, and unit converter tools
    • Engineering unit converter
    • Responsive design for desktop, tablet, and mobile
    • Instant results with clear formulas
    • Input validation and error handling

    Technology

    Built with HTML5, CSS3, and vanilla JavaScript. Deployable as static files on GitHub Pages or any static hosting service.

    How to Use EngineerTools

    Getting Started

    1. Browse the homepage and choose a calculator.
    2. Enter the known values in the input fields.
    3. Click Calculate to see results.
    4. Use Reset to clear inputs and results.

    Tips

    • Leave the unknown field empty and fill the others.
    • Results update instantly after clicking Calculate.
    • Formulas and explanations are shown below every result.
    • Use the search bar on the homepage to quickly find a calculator.

    Keyboard Accessibility

    All buttons and inputs are keyboard accessible. Use Tab to navigate and Enter to activate.
